# Koment tap

Homebrew tap for [Koment](https://github.com/nandzz/koment) — leave inline notes on
code and let Claude Code act on them.

```sh
brew install --cask nandzz/koment/koment
```

To upgrade:

```sh
brew upgrade --cask koment
```

To remove the app and everything it wrote:

```sh
brew uninstall --zap --cask koment
```
